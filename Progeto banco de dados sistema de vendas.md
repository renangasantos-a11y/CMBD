** projeto banco de dados de um sistema de vendas **

este projeto foi desenvolvido para a criação de um banco de dados relacional
aplicado a um sistema de vendas.

a primeira parte do projeto contem a representação do modelo do DB atraves de 
um disgrama de entidade-relacionamento.

criação das tabelas:
 - clientes;
 - produtos;
 - pedidos;
 - fornecedores;
 - compras.

o progeto possui um codigo fonte revisado e documentado.
