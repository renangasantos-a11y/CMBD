** Contextualização **
uma empresa deseja organizar melhor seus dados de vendas. atualmente as informações estão dispersas em
planilhas e não há um sistema centralizado para consultas rápidas. A direção criar um banco de dados 
relacional para armazenar dados de clientes, produtos e pedidos, permitindo análise mais eficientes e relatórios
confiáveis

** desafio **

implementar um banco de dados em SQL q atenda as necessidades da empresa. O desafio envolve:
- modelagem das tabelas necessárias (clientes,produtos,pedidos).
- criação das tabelas com chaves primarias e estrangeiras.
- inserção dos dados ficticios para simular o funcionamento da loja.
- consultas SQL que respondam ás seguintes perguntas.
- quais clientes realizaram mais compras?
- quais produtos mais vendidos no ultimos mês?
- listar os pedidos que ultrapassaram determinado valor?

** resultados esperados **
- um banco de dados funcional criado em SQL que poderá ser utilizado em aplicações reais.
- compreender como funcionam as relações entre as tabelas de um banco de dados.
- criar script de inserção . alteração e exclusão de dados.
- um conjunto de consultas SQL que respondam ás perguntas propostas.
- empregar técnicas na normalização dos dados.
